## 🎮 Features & Mechanics
* **Top-Down Player Movement:** Smooth movement using Godot's `CharacterBody2D`.
* **Vehicle AI:** Vehicles NPC will randomly move anywhere, watch out.
* **Health System:** Everytime you crash with any vehicles, your health will drain.

---

## 🛠️ Built With
* **Engine:** [Godot Engine 4.7.2 C#](https://godotengine.org/)
* **Language:** C#
* **Art and Tools:** Custom 2D Pixel Sprites using [LibreSprite 1.3](https://libresprite.github.io/#!/)

---

## 🕹️ Controls
| Action | Key / Input |
| :--- | :--- |
| **Move Up** | `W` |
| **Move Down** | `S` |
| **Move Left** | `A` |
| **Move Right** | `D` |
